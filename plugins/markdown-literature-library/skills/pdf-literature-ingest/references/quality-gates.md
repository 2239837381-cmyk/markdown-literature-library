# PDF 转换质量门槛

## 合格

- 输出非空，题名、摘要和主要章节顺序可识别。
- 连续段落没有明显跨栏串行；参考文献与正文边界基本可辨。
- 关键表格、公式或图注即使不能完整还原，也已在报告中明确标记。

## 需要复核

- 文本少于配置阈值、替换字符过多、重复页眉页脚主导正文。
- 首选转换器失败后由 `pypdf` 降级提取的文本；即使字符数充足，仍需抽样核对版面与章节顺序。
- 扫描图像、手写内容、受密码保护或复制文字覆盖率明显不足。
- 双栏顺序错乱，关键表格、公式、图注或参考文献严重缺失。

## 处理规则

- 抽样至少覆盖首页/摘要、正文中部和参考文献附近页面。
- OCR 不是默认步骤。说明原因并获得用户授权后才能调用本地 OCR。
- `pypdf` 仅是本地文本恢复路径，不自动替代 OCR 或版面识别；通过人工复核后才能交给下游分析。
- 转换或 OCR 结果必须保留 PDF 文件名映射，不能脱离原件单独成为最终证据。
